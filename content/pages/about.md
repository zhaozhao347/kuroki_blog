## 这个站点

这是一个用 Vue 3 + TypeScript + Vite 搭建的个人博客，视觉语言参考了现代设计工作室的排版习惯：
边到边的栅格、克制的配色、大量留白。

内容以技术笔记与设计随笔为主。项目本身也是一个练手场 ——
每加一个功能，尽量顺便把工程结构理顺一点。

## 技术栈

- **前端** —— Vue 3 · TypeScript · Vite
- **状态与路由** —— 组件本地状态 · Vue Router
- **后端** —— 无（纯静态站，GitHub Pages）
- **样式** —— 原生 CSS · 设计令牌

## 最近在做

1. 把设计系统沉淀成可复用的 CSS 变量
2. 把 Markdown 文章的写作与发布流程再理顺一点
3. 每周写一篇，不求长，但求想清楚
